# Amartha Case Test

This repository contains solutions to technical case studies provided by Amartha, demonstrating proficiency in building scalable and maintainable Go applications

## Project Structure
`case-1-billing-engine/`: Implements a billing engine that processes transaction data and generates billing reports.

`case-2-reconciliation-service/`: Develops a reconciliation service to match and verify transactions between different data sources.

## Getting Started

- Clone the repository:
```bash
git clone https://github.com/khalidsaifuddin/amartha-case-test.git
cd amartha-case-test
```
- Navigate to the desired case directory:
```bash
cd case-1-billing-engine
# or
cd case-2-reconciliation-service
```
- Open readme.MD file in the respective case directory for specific instructions on how to run the application and tests.
